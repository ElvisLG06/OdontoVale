# OdontoVale

App web (móvil) para que la Dra. Valeria lleve el control de sus atenciones odontológicas.

- **Hoy:** agenda del día y buscador de pacientes.
- **Perfil del paciente:** datos, odontograma interactivo (FDI), evoluciones, presupuesto y pagos, tratamientos realizados y citas.
- **Calendario:** vista mensual, con citas de control a 1, 3, 6 o 12 meses.

Los datos se guardan en el navegador del dispositivo (localStorage). Usa **Ajustes → Copia de seguridad** para descargar o restaurar un respaldo.

Es un solo archivo, `index.html`, publicado con GitHub Pages.
